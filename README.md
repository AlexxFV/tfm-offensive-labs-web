# TFM Offensive Labs Web

Web estática para presentar y distribuir los cuatro laboratorios Docker del TFM.

## Vista local rápida

Puedes abrir `index.html` directamente en el navegador o usar un servidor estático:

```powershell
cd C:\Users\afvle\tfm\web
npx serve .
```

## Despliegue en Vercel

1. Sube esta carpeta `web` a un repositorio o usa Vercel CLI.
2. Configura el proyecto como sitio estático.
3. No hace falta comando de build.
4. Directorio de salida: `.`

## Descargas

Los ZIP de los laboratorios están en `downloads/`.
